# Uplift-моделирование для таргетинга SMS (X5 RetailHero)

[English](README.md) · **Русский**

**Вопрос:** каким клиентам программы лояльности отправлять промо-SMS? Не тем, кто с наибольшей вероятностью купит, а тем, у кого вероятность покупки **растёт благодаря SMS**.

**Стек:** DuckDB (признаки по 45,8 млн строк) · Python · CatBoost · scikit-uplift · scikit-learn · matplotlib

**Данные:** [X5 RetailHero Uplift Modeling](https://ods.ai/competitions/x5-retailhero-uplift-modeling) — рандомизированная SMS-кампания X5 Group: 200 039 клиентов с флагом treatment/control и фактом покупки, плюс история покупок до кампании (45 786 568 строк чеков, 8 045 229 чеков, 400 162 клиента).

---

## Результаты

5 повторных стратифицированных разбиений 70/30; метрики на отложенной выборке, среднее ± std. Графики и цифры по децилям — по первому разбиению.

| Модель | uplift@30% | Qini AUC | Uplift AUC |
|---|---:|---:|---:|
| Модель отклика (предсказывает P(покупки), игнорирует treatment) | 2,19 ± 0,32 п.п. | −0,0069 ± 0,0019 | −0,0108 ± 0,0030 |
| **S-learner** | **6,73 ± 0,20 п.п.** | **0,0179 ± 0,0015** | **0,0274 ± 0,0021** |
| T-learner | 6,60 ± 0,26 п.п. | 0,0153 ± 0,0011 | 0,0230 ± 0,0016 |
| Class transformation | 6,49 ± 0,58 п.п. | 0,0159 ± 0,0010 | 0,0242 ± 0,0016 |
| *Случайный таргетинг (средний эффект)* | *3,32 п.п.* | *0* | *0* |

**Выводы**

1. **SMS работает, но неравномерно.** Средний эффект +3,3 п.п. (63,7% против 60,3% покупателей). В топ-30% клиентов по S-learner — **+6,7 п.п., вдвое выше среднего**; в топ-10% — +13,8 п.п.
2. **Таргетинг на «вероятных покупателей» хуже случайного.** У модели отклика отрицательный Qini: те, кто купит и так, — как раз те, на кого SMS не влияет. Это главный аргумент за uplift-модели вместо моделей склонности к покупке.
3. **30% рассылки дают 62% дополнительных покупателей.** На 1 000 SMS: ~67 дополнительных покупателей в топ-30% против ~33 при рассылке всем.
4. **«Спящих собак» в этой кампании нет.** Наблюдаемый uplift неотрицательный во всех децилях, поэтому при бесплатных SMS максимум дополнительных покупателей даёт рассылка всем. Таргетинг оправдан стоимостью контакта: отправлять в топ-k, пока uplift × маржа с покупки выше стоимости SMS.
5. **Простой S-learner лучший**; разница между uplift-подходами (≈0,2 п.п. на 30%) мала по сравнению с отрывом от модели отклика (≈4,5 п.п.).

## Признаки

33 признака клиента, все посчитаны по покупкам **до** кампании (без утечки таргета) одним SQL-скриптом в DuckDB (`src/features.sql`, ~25 с на ноутбуке с 8 ГБ RAM — сжатый CSV на 670 МБ читается потоково, а не загружается в память):

- **RFM и активность:** число чеков, сумма и средний чек, давность, активные дни, средний интервал между покупками, активность за 7/30 дней, доля трат за 30 дней
- **Корзина:** позиций и товаров в чеке, уникальных товаров, число магазинов
- **Программа лояльности:** начисленные и списанные баллы (обычные/экспресс), доля чеков с оплатой баллами, возраст карты, задержка от выдачи карты до первого списания
- **Демография:** возраст (значения вне 14–100 заменены пропуском), пол

## Методы

- **Модель отклика:** P(Y=1 | X) — обычная «склонность к покупке», бейзлайн.
- **S-learner:** одна модель P(Y=1 | X, W); uplift = f(X, 1) − f(X, 0).
- **T-learner:** отдельные модели на treatment и control; uplift = f₁(X) − f₀(X).
- **Class transformation:** Z = Y·W + (1−Y)(1−W); при сплите 50/50 uplift = 2·P(Z=1 | X) − 1.
- **Метрики:** uplift@30% — разница доли покупателей между treatment и control в топ-30% (считается по группам); Qini AUC и uplift AUC — площадь между кривой модели и случайным таргетингом.

## Как запустить

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
mkdir -p data && for f in clients.csv.gz uplift_train.csv.gz purchases.csv.gz; do
  curl -L -o data/$f https://sklift.s3.eu-west-2.amazonaws.com/$f; done   # ~680 МБ
python src/build_features.py
python src/train.py      # ~5 мин
```

## Ограничения

- Кампания одна; оценки uplift могут не переноситься на другие офферы, каналы и сезоны.
- Нет данных о стоимости контакта и марже, поэтому эффект выражен в дополнительных покупателях, а не в рублях.
- Гиперпараметры фиксированы (CatBoost, 400 деревьев, глубина 6) и не подбирались под каждый подход; тюнинг может поменять порядок близких uplift-моделей.
- Таргет бинарный (покупка / нет); для uplift по выручке нужен другой таргет.
